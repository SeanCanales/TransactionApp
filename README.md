--Basic Transaction App

--Overview

This basic transaction app is a Java application that allows users to manage financial transactions through a graphical user interface. 
The application uses Java Swing to provide an interface for entering and viewing transaction details, Spring Boot to manage application components, and database CRUD operations to handle transaction data.
This project was developed to practice Java programming, GUI development, database integration, and dependency injection using Spring Boot.

--Features

*Create transactions: Enter transaction details, including account ID, category, merchant, description, and price.
*View transactions: Retrieve and display existing transactions from the database.
*User-friendly interface: Interact with transaction data through a Java Swing GUI.
*Database integration: Store and retrieve transaction records using the application's CRUD methods.
*Input handling: Convert user input into the appropriate data types and handle invalid numeric values.
*Update transactions: Modify existing transaction records.
*Delete transactions: Remove transactions from the database.
*View transactions: View all transactions in the database.

--Technologies Used

*Java
*Java Swing
*Spring Boot
*Spring Dependency Injection
*Database integration through CRUD methods
*Maven
